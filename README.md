# 🔥 FFIS — Forest Fire Intelligence System

Інтелектуальна система прогнозування ризику лісових пожеж на основі 
машинного навчання, що охоплює два регіони Північної Африки — 
Марокко та Алжир.

## 🎯 Можливості системи

- **Прогнозування в реальному часі** — оцінка ризику для 
  довільної точки регіону через веб-інтерфейс
- **Мультирегіональність** — дві незалежні моделі 
  (Марокко: XGBoost, 158 ознак; Алжир: Random Forest, FWI-ознаки)
- **Пояснювальний ШІ** — SHAP-аналіз з глобальним та 
  локальним (waterfall) поясненням прогнозу
- **Геопросторова карта** — теплова карта ризику + 
  супутникові шари NASA GIBS (MODIS True Color, NDVI)
- **AI-рекомендації** — генерація порад для служб 
  пожежної безпеки через локальну LLM (Ollama)
- **Сценарна симуляція** — аналіз "що якщо" для 
  різних метеорологічних умов

## 📊 Результати моделювання

| Модель | AUC-ROC | F1 | Accuracy |
|--------|---------|-----|----------|
| XGBoost (Марокко) | **0.9905** | 0.953 | 0.952 |
| Random Forest (Марокко) | 0.9767 | 0.919 | 0.915 |
| SVM | 0.9208 | 0.861 | 0.854 |
| Logistic Regression | 0.8975 | 0.829 | 0.820 |

## 🛠️ Технологічний стек

- **ML:** Python, scikit-learn, XGBoost, SHAP
- **Веб:** Streamlit, Plotly
- **Геопростір:** Folium, NASA GIBS/FIRMS API
- **LLM:** Ollama (llama3.2:3b, локально)
- **Дані:** Morocco Wildfire Prediction (934K спостережень), 
  Algerian Forest Fires (UCI)

## 🚀 Запуск

### 1. Встановити залежності
pip install -r requirements.txt

### 2. Налаштувати змінні середовища
cp .env.example .env
# Заповнити свої ключі в .env

### 3. (Опціонально) Встановити Ollama для AI-рекомендацій
# https://ollama.com/download
ollama pull llama3.2:3b

### 4. Навчити моделі
python scripts/train_model.py

### 5. Запустити застосунок
streamlit run main.py
